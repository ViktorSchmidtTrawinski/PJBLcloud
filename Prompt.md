Precisamos criar um frontend com React e TypeScript para um aplicativo de delivery de comida. Para estilização, utilize o Tailwind.

Crie o projeto com Vite e nesse primeiro momento desenvolva somente a tela de login e cadastro. O consumo da API deverá ser feito com Axios e a conexão será com a Azure (Azure Functions), portanto já deixe pronta a comunicação do CRUD completo para apenas alterarmos a env da URL e autenticação posteriormente.

Utilize um estilo simples, mas com padronização de cores, layout e principalmente componentização. 

O CRUD de cadastro deve incluir:
- Nome completo
- CPF
- Data de nascimento
- Endereço completo (rua, número, complemento (opcional), CEP, cidade, bairro)
- Número de celular
- Senha

Crie as devidas validações para esses campos, com mensagens de erros e impossibilidade de prosseguir em caso de dados faltantes ou incorretos.
